# README for "Selection and Heterogeneity in the Returns to Migration" (Cenci, Kleemans, Tjernström)

## Overview

The code in this replication package estimates heterogeneous returns to rural-urban migration using a group random coefficient (GRC) model, following the linear-comparative-advantage (LCA) restriction described in the paper.
The pipeline builds analysis panels from three household-survey sources (China, Indonesia, Tanzania), estimates the model by GMM in Stata, attaches weak-identification-robust confidence intervals for the slope parameter via a Python routine called from Stata, and produces all tables and figures in the paper.
The replicator runs a single master do-file, `0_master.do`, which chains every step from raw data to final output.
The replicator should expect the full pipeline, including the GRC extras block, to take on the order of two days on a modern desktop; see Computational requirements below for a per-block breakdown.

## Description of programs/code

The programs run in the order below, matching `0_master.do`.
Every script assumes that `$dir`, `$scripts`, `$dirdata`, `$logs`, and `$output` are already set; `0_master.do` sets `$dir` per user, then includes `0_path_config.do` to derive the rest and `0_programs.do` to load every shared estimation and table-building program.

Each numbered script below also writes its own run log to `scripts/logs/`, named after the script; the entries below note only the outputs beyond that log.

#### `0_CHN_hukou_restrictions.do`

This script builds four China analysis subsamples defined by hukou (household registration) status, so the paper can test whether the returns-to-migration results hold within institutionally homogeneous subgroups rather than only in the pooled sample.
It splits the panel by whether an individual ever held a rural hukou, ever held an urban hukou, and by which hukou status they held first, since rural and urban hukou holders face different formal mobility restrictions in China and the pooled sample may otherwise mix these regimes.
Hukou is coded so that `hukou == 1` is rural and `hukou == 0` is urban; the rural-only and urban-only files classify individuals by the minimum and maximum hukou value across their observed periods, while the first-hukou files use each individual's earliest observed period.
It reads `data/countries/CHN.dta` fresh in each of its four sections, so the four outputs below are independent of each other and can be regenerated in any order.

- `data/processed/CHN_hukou_rural_only.dta`: individuals who never held an urban hukou.
- `data/processed/CHN_hukou_urban_only.dta`: individuals who never held a rural hukou.
- `data/processed/CHN_hukou_rural_first.dta`: individuals whose earliest observed hukou status was rural.
- `data/processed/CHN_hukou_urban_first.dta`: individuals whose earliest observed hukou status was urban.

#### `1_processData.do`

This script builds every processed analysis dataset the pipeline needs, one country-specification cell at a time.
For each cell it loads the raw or hukou-restricted dataset, applies the choice and outcome definitions, imposes balance where required, constructs migration trajectories and switcher status, builds the GRC estimation scaffolding, restricts to the estimable sample, and saves the result to `data/processed/`.
It is the single upstream data-construction step: every later script reads its inputs from the files this script writes rather than touching the raw country files directly, and the four CHN hukou subset files built by `0_CHN_hukou_restrictions.do` must already exist before this script's hukou sections run.
Every cell uses log per-capita consumption as the outcome.

Outputs follow the pattern `{country}_{balance}[_{choice}][_{Nwaves}].dta`, where balance is `unb` or `bal`, the `_nonag` suffix appears only for the Indonesia non-agricultural cell, and the `_2waves`/`_3waves` suffix appears only for the wave-restricted trajectory cells.

- `IDN_unb.dta`, `IDN_bal.dta`, plus `IDN_unb_nonag.dta` and the `_2waves`/`_3waves` variants for both balance levels.
- `CHN_unb.dta`, `CHN_bal.dta`, plus the `_2waves`/`_3waves` variants for both balance levels.
- `TZA_unb.dta`, `TZA_bal.dta`, plus the `_2waves`/`_3waves` variants for both balance levels.
- `CHN_hukou_rural_only_{unb,bal}.dta`, `CHN_hukou_urban_only_{unb,bal}.dta`, `CHN_hukou_rural_first_{unb,bal}.dta`, `CHN_hukou_urban_first_{unb,bal}.dta`, one pair per hukou subgroup.

The workhorse program, `data_setup` (and its `data_setup_2waves`/`data_setup_3waves` variants), loads the country file, sets the choice variable, defines the outcome and drops missing or non-positive values, imposes the balance restriction, builds trajectories and switcher status, defines covariates, builds the GRC scaffolding, restricts to the estimable sample, and stashes a switcher-inclusion keep-list.
Each saved dataset carries its GRC trajectory contract as dataset characteristics rather than ordinary variables (`_dta[grc_switchers]`, `_dta[grc_always]`, `_dta[grc_never]`) plus its switcher-inclusion keep-list (`_dta[grc_kept_switchers]`, `_dta[grc_keep_threshold]`, `_dta[grc_keep_counts]`); downstream estimation scripts read these characteristics back at load time rather than recomputing them, and the same keep-list is written to a CSV under `output/keeplists/`.
Trajectory codes below the switcher-inclusion threshold are not dropped from the saved file; lumping them into a residual category is a decision made by the downstream reader at load time, not by this script.

#### `2_summaryStats.do`

This script builds the paper's summary statistics tables from the processed country panels, running immediately after data processing and before any regression script so the tables describe the estimation samples as they stand prior to estimation.
For each country it computes means, standard deviations, and urban/rural (or agricultural/non-agricultural) differences for consumption, income, and demographic variables, then writes the results out as LaTeX tables, including one combined table per panel type that places all three countries side by side.
Income appears here only as a descriptive comparison variable, alongside consumption and the demographic controls; it is not used as an outcome anywhere in the estimation pipeline, and it has fewer non-missing observations than the other variables in every table, a discrepancy the table note reports explicitly.

- `summary_stats_{country}_{balance}.tex`: per-country, per-balance table (urban choice, consumption outcome).
- `summary_stats_{country}_{balance}_nonag.tex`: agricultural/non-agricultural version, Indonesia only.
- `summary_stats_{country}_{balance}_2waves.tex` and `_3waves.tex`: non-switcher-restricted versions, all three countries, unbalanced panel only.
- `summary_stats_combined_unb.tex` and `summary_stats_combined_bal.tex`: one landscape table per panel type, with Indonesia, China, and Tanzania as side-by-side column blocks.

The workhorse program, `country_summary_stats` (and its `_2waves`/`_3waves`/`_nonag` variants), calls the `iebaltab` command from the `ietoolkit` package to compare rural status, log consumption, log income, sex, age, education, and household size by location, then reshapes the result into the table's row structure; `sumstats_table` writes the formatted LaTeX file, and `sumstats_combined_table` reruns the country-level computation for all three countries and stacks them side by side.
`copyOverleaf`, used by most later scripts as well, copies a finished table to the manuscript folder when that destination is configured, and is a no-op otherwise.

#### `1b_unbalanced_rank_diagnostic.do`

This script computes rank-condition diagnostics for individuals observed in fewer than the full panel length in each country sample.
It supports an appendix proposition showing that balanced and unbalanced individuals can be pooled in the main estimation: the pooled specification adds a free slope parameter for unbalanced individuals, and that parameter is identified only if the urban-location indicator varies enough within the unbalanced group, including after controlling for covariates.
For each country it computes the urban-location rate among unbalanced person-period observations, the share of that variation left over after controlling for the main covariates, and a three-way split of unbalanced individuals into always-rural, always-urban, and switcher categories, checking that every individual falls into exactly one category.

- `unbalanced_rank_macros.tex`, written to `output/tables/`: one set of LaTeX macros per country, read directly into the paper's appendix text so the reported figures always match the current data.
- A run log recording the underlying counts, shares, and regression R-squared values per country.

This script relies only on built-in Stata commands, no shared programs from `0_programs.do`, and it will stop with an error if the always-rural/always-urban/switcher split does not account for every unbalanced individual, which would indicate a data problem upstream.

#### `3_OLS_uGRC.do`

This script runs the paper's baseline OLS and fixed-effects regressions of log per-capita consumption on location choice, ahead of the GRC estimation in later scripts.
It produces three tables: the main unbalanced-panel result for urban location, a balanced-panel robustness version of the same specification, and an Indonesia-only version that uses non-agricultural employment as the location choice instead of urban residence.
Each table stacks all three countries in a three-panel layout and runs six columns per country that add covariates and fixed effects one at a time, so a replicator can see how the urban coefficient moves as the specification tightens; standard errors are clustered at the individual level throughout.

- `output/tables/OLS_consumption_urban_unb.tex`: the main table.
- `output/tables/OLS_consumption_urban_bal.tex`: the balanced-sample robustness table.
- `output/tables/OLS_consumption_nonag_unb.tex`: the Indonesia-only non-agricultural table.

The six columns run: choice only with survey-wave fixed effects; adding female; adding age squared; adding education and its square; the same covariates restricted to the migrant (switcher) subsample; and the same covariates with individual fixed effects added.
The individual-fixed-effects column is estimated first, since its sample, after listwise deletion on covariates and fixed effects, sets the common sample for the other columns.
Two shared programs do the work: `data_setup` (described under `1_processData.do` above) builds the choice, outcome, trajectory, and covariate variables for the balanced-panel and non-agricultural sections, while the unbalanced section opens the processed files directly since they already carry those variables; `reghdfe_regressions` runs and stores the six regressions per country, and `create_panel_tex_table` assembles the stored estimates into the three-panel LaTeX table.

#### `4_GrRC.do`

This script runs the paper's central estimation: the restricted group random coefficient (GRC) model, fit by GMM, for the return to urban location.
It estimates the model separately for each of the three countries and for two panel structures (unbalanced and balanced), and within each of those six cells it runs four covariate specifications, so it produces the full set of urban-choice consumption results that the paper's main results tables and figures draw on.
Each input dataset must carry the GRC trajectory contract as dataset characteristics, stashed by `1_processData.do`; `setup_grc_estimation` reads these back and exits with an error if they are missing.

Estimation results (`.ster` files) are written to `output/`, named `grc_{country}_{spec}_{col}.ster`, where `spec` is `cuu` (consumption, urban, unbalanced) or `cub` (consumption, urban, balanced), and `col` is the covariate column: `ct` (time fixed effects only), `c1` (adds female), `c2` (adds age squared), or `ca` (adds education and its square).
A fifth column, `c0` (no covariates), is coded but commented out because it often failed to converge; this applies to every GRC script that shares the same covariate ladder.
Each main fit also writes four derived files with the same stem: `_n` (the extrapolated never-migrant return), `_a` (the average always-urban return), `_d` (the per-trajectory return for every switcher trajectory, plus a joint equality test, wrapped so a subsample too small to support every trajectory skips only this file), and `_g` (the sample-share-weighted average return across switcher trajectories, Delta_avg), together with an `_esample.dta` marker recording the pid-period keys actually used, since a `.ster` file does not retain `e(sample)`.
In total the script produces 6 cells by 4 columns, 24 main fits, each with up to 4 derived files.

Four shared programs drive every GRC estimation script in the pipeline.
`set_covariate_globals` defines the three covariate ladders used across columns (`$covs_gmm` = female; `$covs_gmm2` adds age squared; `$covs_gmm_all` adds education and its square).
`setup_grc_estimation` reads the trajectory contract off the dataset, sets the `$switchers`/`$always`/`$never` globals, and applies the switcher-inclusion rule, lumping any switcher trajectory with too few individuals observed in both locations into the unbalanced (or, for balanced samples, dropped) cell so every downstream estimator shares one consistent switcher set.
`initial_values` runs an auxiliary OLS regression for GMM starting values and selects the base switcher trajectory as the one with the highest t-statistic on its choice interaction among trajectories that clear the minimum observations-per-wave threshold.
`run_grc` runs the GMM fit, computes Hansen's J-test for overidentification and a joint equality test across the mu parameters, times the fit, saves the main `.ster` plus the four derived files above, and supports a resume-on-interrupt skip if the `_g` file already exists; it calls `define_switcherpars` internally to build the GMM moment expression for the switcher-specific mu parameters relative to the base trajectory.

The GMM iteration cap is set once, project-wide, via `$grc_max_iter` (100 by default) in `0_path_config.do`, and applies to every GRC script that shares it.
Standard errors are clustered on individual throughout; runtime varies by country and sample size, with the larger unbalanced China sample taking the longest of the six cells.
Downstream, `5b_inversion.do` attaches confidence intervals to these `.ster` files without re-running the GMM, and `10_make_tables.do` and `11_make_figures.do` read the saved files rather than re-estimating, so refreshing a table or figure after this script runs does not require rerunning it.

#### `5b_inversion.do`

This script attaches weak-identification-robust confidence intervals for the linear-comparative-advantage (LCA) inversion to the main GRC estimation files.
For each country and covariate specification it computes 90 percent and 95 percent confidence intervals for the slope parameter phi and for the three trajectory-specific returns (never-migrant, average-switcher, always-migrant), then writes those intervals back onto the saved GRC results.
It is split out from `4_GrRC.do` because the inversion is a comparatively fast calculation, so a replicator who only needs to refresh the confidence intervals does not have to re-run the slow GMM fits that produce the point estimates.
No new files are created; each of the four estimation files per country and covariate set (the main file plus the never-migrant, average-switcher, and always-migrant companions) is reloaded, given additional results (point estimate at the minimum Wald statistic, the statistic itself, degrees of freedom, retained observation count, 90 and 95 percent interval bounds, a count of any disconnected interval segments, and formatted text versions of both intervals), and re-saved under its original name.

The Stata program that does the attaching, `attach_inversion_ci`, calls a Python module, `lca_inversion.py`, in `explorations/python-grc`, through Stata's built-in Python integration; the entry point is `attach_inversion_for_stata`, and the Python environment Stata calls into needs `numpy`, `pandas`, `statsmodels`, and `scipy`.
When present, the script uses the `_esample.dta` marker that `4_GrRC.do` writes alongside each estimation file to compute on the identical estimation sample; when absent, it reconstructs the sample from missing values and prints a warning.
Run this script after `4_GrRC.do` and before `10_make_tables.do`, which reads the confidence intervals attached here.
A country-and-covariate-set cell is skipped automatically if its main estimation file is not found, and setting the global `skip_if_exists` to 1 skips any cell that already carries attached intervals, so a partial run only fills in what is missing.

#### `5_GrRC_NonAg.do`

This script estimates the restricted GRC model for Indonesia using non-agricultural sector employment, rather than urban location, as the binary choice variable, letting the analysis test whether results are similar when the treatment is defined by sector rather than location.
It runs on the unbalanced panel with log per-capita consumption as the outcome, and produces four estimates that add covariates one at a time: time fixed effects only, then plus sex, then plus age squared, then plus education and its square.

- `grc_IDN_cnu_ct`, `grc_IDN_cnu_c1`, `grc_IDN_cnu_c2`, `grc_IDN_cnu_ca`: the four covariate columns, tagged `cnu` for consumption, non-agricultural choice, unbalanced panel.
- As in `4_GrRC.do`, a fifth, no-covariate column (`c0`) is coded but commented out and not produced by a normal run.

It calls the same four shared programs described under `4_GrRC.do` above (`set_covariate_globals`, `setup_grc_estimation`, `initial_values`, `run_grc`), reads `data/processed/IDN_unb_nonag.dta`, and does not build any table itself; `10_make_tables.do` reads these `.ster` files to build the corresponding table.

#### `6_OLS_uGRC_hukou.do`

This script runs OLS and fixed-effects regressions of log per-capita consumption on urban location for the four China hukou subgroups built by `0_CHN_hukou_restrictions.do`, testing whether the returns to urban location differ by hukou regime, since institutional barriers tied to hukou status are a candidate explanation for heterogeneity in the pooled China results.
Each subgroup is run on both the unbalanced and the balanced panel, eight regression blocks in total, and every block produces the same six-column layout as `3_OLS_uGRC.do`: a bare specification, then covariates and fixed effects added one at a time, then a migrants-only sample.

- `output/tables/OLS_CHN_hukou_{subgroup}_consumption_urban_{balance}.tex`, one per subgroup (`rural_first`, `urban_first`, `rural_only`, `urban_only`) by balance (`unb`, `bal`).

It reuses `reghdfe_regressions` and `create_panel_tex_table`, described under `3_OLS_uGRC.do` above, opening each hukou dataset directly rather than constructing new variables.
The eight blocks are independent of each other and can be run in any order; the balanced-panel tables' footnotes describe them as repeating the corresponding unbalanced-panel analysis, so the two should be read as a matched pair per subgroup.

#### `7_GrRC_hukou.do`

This script estimates the restricted GRC model separately for the four China hukou subsamples.
The pooled China sample rejects the model's overidentification test (Hansen's J), and splitting the sample by hukou regime resolves that rejection, pointing to institutional heterogeneity across regimes rather than a misspecified model, so returns to urban location can be reported separately for each regime instead of pooling regimes that behave differently.
Rural-only and urban-only hold hukou fixed across the panel; rural-first and urban-first allow hukou to change over time and are named for the individual's hukou status in the first observed wave.
For each subgroup the script runs both an unbalanced-panel and a balanced-panel version, eight input datasets in total, each with the same four covariate columns as `4_GrRC.do`, plus a fifth, no-covariate column that is coded but commented out.

- One `.ster` file per subgroup, panel balance, and covariate column, named `grc_CHN_{hukou}_{spec}_{col}`, where `hukou` is `rf` (rural-first), `uf` (urban-first), `ro` (rural-only), or `uo` (urban-only): for example, `grc_CHN_rf_cuu_ct` is the rural-first, unbalanced-panel fit with time fixed effects only.
- One `initial_{country_short}.ster` per subgroup-balance combination, storing the GMM starting values.

It calls the same shared programs described under `4_GrRC.do` above, and does not produce LaTeX tables itself; `10_make_tables.do` reads these `.ster` files back and formats them.

#### `5c_inversion_hukou.do`

This script attaches the same weak-identification-robust confidence intervals as `5b_inversion.do`, but to the GRC estimates for the rural-hukou-first and urban-hukou-first subsamples only; the rural-hukou-only and urban-hukou-only subsamples are not covered by this pass.
It reads the `.ster` files that `7_GrRC_hukou.do` produces for the urban-choice, consumption-outcome, unbalanced-sample specification, across all five covariate columns, and updates each of the four companion files per subsample and column (the parent phi estimate plus the `_n`, `_g`, and `_a` files) in place, using the same Python module and dependency described under `5b_inversion.do` above.
Run this script after `7_GrRC_hukou.do`; if a required parent `.ster` file is missing for a given subsample and covariate column, the script logs a skip message and continues rather than stopping.

#### `8_learning.do`

This script tests for learning effects by estimating how the return to location changes with the number of periods spent there since a move.
For each switcher it builds period-since-migration indicators and regresses log per-capita consumption on those indicators, first with OLS and then adding time and individual fixed effects; a flat or increasing profile across periods is evidence against pure static sorting and consistent with on-the-job learning in the new location.
It runs for Indonesia and China only, since Tanzania's panel is too short to identify separate period-since-migration effects; Indonesia's columns report up to four periods of exposure, China's up to three, reflecting the shorter panel.

- `output/tables/OLS_IDN_consumption_learning_bal.tex`
- `output/tables/OLS_CHN_consumption_learning_bal.tex`

`reghdfe_regressions_learn_IDN` and `reghdfe_regressions_learn_CHN` run the four-column OLS and fixed-effects regressions (no fixed effects; time fixed effects; time fixed effects plus covariates, a female indicator, age squared, and years of schooling and its square; time and individual fixed effects) and store joint significance tests across the period indicators, while `create_panel_tex_table_learn_IDN` and `_CHN` format the results into the tables above.
Standard errors are clustered at the individual level; the script reads the balanced-panel processed datasets and requires the `reghdfe` package.

#### `9_GRC_extras.do`

This script runs the GRC variants that add one extra, non-period regressor on top of the main covariate ladder, in two families.
The experience family adds a measure of migration or work experience (raw experience, its maximum, or a share-of-time version of either) to the consumption-on-location GRC fit, for the main urban-choice specification in each of the three countries and for Indonesia's non-agricultural-choice specification.
The birth family adds an urban-birth-region indicator, Indonesia only, again across the urban-choice and non-agricultural-choice specifications.
Each call covers one country, specification, and extra-regressor family at a time, then fits four versions of that cell with progressively richer covariates.
These regressor families used to live in six separate do-files; consolidating them here keeps the naming and covariate ladder uniform across families.

- `.ster` files under `output/`, named `grc_{country}_{spec}_{family}_{col}[_suffix]`, where `family` is `exp`, `maxexp`, `expsh`, `maxexpsh`, or `birth`, and `col` runs `c1` through `ca`, from the extra regressor alone up to the extra regressor plus the full covariate set.
- Each covariate column saves up to five companion files, following the same `_n`/`_a`/`_d`/`_g` convention described under `4_GrRC.do` above.
- The script issues 31 country-specification-family calls, each producing four covariate-column fits, so the full block writes on the order of several hundred `.ster` files; `10_make_tables.do` builds the corresponding tables and this script does not write tables itself.

The key program, `run_grc_with_extra_regressor`, looks up which family a given regressor belongs to, resolves the implied choice, outcome, and panel balance, opens the matching dataset, builds the GRC scaffolding, sets initial values and the base trajectory, and runs four `run_grc` fits stacking the extra regressor onto increasingly rich covariate sets.
This is the longest-running block in the pipeline, plausibly on the order of a day or more if run serially, because it repeats the full GMM fitting routine well over a hundred times.
The `scripts/utilities/` slice drivers described below split part of this block into independently runnable pieces, and launching them in separate concurrent Stata sessions cuts wall-clock time roughly in proportion to the number of concurrent sessions, since a stored `.ster` file already on disk lets a rerun skip a completed cell rather than refit it.

#### `10_make_tables.do`

This script builds every GRC LaTeX table used in the paper from previously saved estimation files, without running any estimation itself, so tables can be regenerated, for example after a caption or formatting change, without paying the cost of re-fitting the GMM models.
Each table is produced by an explicit, separately runnable call rather than a loop, so any single table can be rebuilt on its own; if a given table's underlying `.ster` file has not yet been produced, its call fails or is skipped, and the relevant estimation script needs to run first.
It reads the main, non-agricultural, hukou-subgroup, heterogeneity, and extras-family estimates produced by `4_GrRC.do`, `5_GrRC_NonAg.do`, `7_GrRC_hukou.do`, and `9_GRC_extras.do`, reopening the processed country datasets only for the heterogeneity tables, to recover trajectory labels for the switcher coefficients.

- Main GRC tables: `GRC_{country}_consumption_urban_{unb,bal}.tex` for IDN, CHN, TZA (six files).
- Non-agricultural table: `GRC_IDN_consumption_nonag_unb.tex`.
- Hukou tables: `GRC_CHN_hukou_{subgroup}_consumption_urban_{unb,bal}.tex` for each of the four subgroups (eight files).
- Heterogeneity tables: `hetDelta_table_{country}.tex` and `hetmu_table_{country}.tex` for IDN, CHN, TZA (six files).
- Extras-family tables: one file per country-specification-regressor combination, covering the four experience regressors across the unbalanced and balanced urban-choice specifications and the non-agricultural specification for Indonesia, plus the urban-birth regressor for Indonesia (forty-four files in total).

`grc_tex_table_trend` formats the main, non-agricultural, and hukou-subgroup estimates into the standard four-column GRC table layout; `het_table_delta` and `het_table_mu` format the per-trajectory heterogeneity estimates; `extras_tex_table` formats each experience- or birth-regressor cell, reading the disambiguated `.ster` naming convention directly; `copyOverleaf`, described under `2_summaryStats.do` above, copies each generated table to the manuscript folder when enabled.

#### `11_make_figures.do`

This script builds every figure in the paper's results section: heterogeneity coefficient plots of the switcher-trajectory returns and rural-consumption levels, robustness coefficient plots comparing the main specification against alternative-regressor specifications, and stacked bar charts of migration-trajectory composition by minimum required survey waves.
It is the final figure-assembly step of the pipeline: aside from two small auxiliary regressions used only for the heterogeneity plots, it reads results earlier scripts already saved to disk rather than estimating anything new.
The script covers the consumption, urban, unbalanced combination throughout; China does not appear in the robustness coefficient plots, which are produced only for Indonesia and Tanzania.

All figures export as both PDF and PNG, to `output/figures/`.

- `hetplotDelta_consumption_urban_unb_Fcovars` and `_Fnocovars`: three-country combined coefficient plots of trajectory-specific returns to urban location, with and without covariates and time fixed effects.
- `hetplotmu_consumption_urban_unb_Fcovars` and `_Fnocovars`: the same, for trajectory-specific average rural consumption levels.
- `robustness_coefplot_IDN` and `robustness_coefplot_TZA`: coefficient plots of the slope parameter, the never-migrant return, and the average return, compared across the main specification and each robustness variant.
- `trajectories`: stacked bar chart of trajectory composition by country, balanced sample; `trajectories_fullsample`, `trajectories_2waves`, and `trajectories_3waves` repeat this for the full sample and the two- and three-wave-minimum samples.

`setup_grc_estimation`, described under `4_GrRC.do` above, reads back the trajectory contract stashed on each processed dataset; `heterogeneity_plots` fits the two auxiliary regressions per country, tests equality of the trajectory coefficients, and draws the Delta and mu coefficient plots; `grc_robustness_coefplot` reads existing saved results across the main specification and each robustness variant and plots them together.
The three trajectory-composition sections each load a different version of the processed data, since the trajectory variable used for grouping is defined only for individuals meeting the corresponding minimum-wave threshold; for Tanzania, which has at most three survey waves, the three-wave threshold effectively requires every wave and so matches the balanced-sample chart.
Trajectory bar-chart PNGs export at width 3600 for print resolution.

#### `17_verdier_robust.do`

This script estimates a robustness variant of the GRC model in which the switcher-trajectory instruments are replaced with residuals from regressing treatment on the individual's cluster index, following the identification argument in Verdier (2020, Journal of Applied Econometrics, Online Appendix Section F).
Because the returns parameter is then identified off within-cluster variation in treatment, the estimate is robust to cluster-level confounders in the outcome, which the baseline GRC specification does not guard against.
It produces the paper's robustness subsection on allowing cluster-specific trajectory intercepts, fitting every country and covariate specification under both one-step and two-step GMM so the two variants can be compared before choosing which one to report.

- Estimation results at `output/vv_{country}_{os,ts}_covs_*.ster`, five covariate specifications by two GMM step variants by three countries, thirty fits in total, each with the same `_n`/`_a`/`_d`/`_g` companion files described under `4_GrRC.do` above.
- Paper tables at `output/tables/verdier_robust_{onestep,twostep}_{country}_consumption_urban_unb.tex` (six tables), with copies of the one-step tables at `output/tables/GRC_{country}_consumption_urban_unb_cluster.tex`, the names the paper's cluster-pooling robustness subsection reads from.
- One keeplist file per country at `output/keeplists/vv_{country}_keeplist.csv`, recording which switcher trajectories were kept versus pooled and why.
- The five-row baseline-versus-cluster summary table is produced by `17b_cluster_summary.do`, not this script.

`setup_grc_estimation, nolump` loads and prepares each sample without pooling any switcher trajectory, since this script applies its own inclusion rule afterward through `gen_vfirst`, each individual's first-wave cluster index (province for Indonesia and China, region for Tanzania), and `compute_switcher_keeplist`, which keeps a trajectory only if enough distinct clusters have a member observed in both the rural and urban state, a cluster count rather than the individual count used in the main GRC scripts; `write_keeplist_csv` records the decision to the audit CSV.
`initial_values` and `run_grc_robust_vv` then compute starting values and fit the GMM model, respectively, with standard errors clustered on the cluster index; `grc_tex_table_trend_robust` formats the results.
A full pass fits thirty GMM models, so expect a long running time; the global `skip_if_exists` defaults to 1, skipping any cell whose result file already exists, and an optional Python comparison step, gated by the `runDashboard` global, writes a one-step-versus-two-step memo without affecting the LaTeX tables either way.

#### `17b_cluster_summary.do`

This script checks whether the paper's main GRC estimates are sensitive to how observations are grouped for clustering.
It refits the model with cluster-robust standard errors, following the same Verdier-style approach as `17_verdier_robust.do`, for five country and subgroup rows (Indonesia; China pooled, rural-first, and urban-first; Tanzania), then builds a summary table comparing the baseline and cluster-robust versions of two key parameters: the comparative-advantage slope and the extrapolated never-migrant return.
Only the one-step, full-controls specification is covered; two-step and per-country appendix versions of this comparison are not produced here.

- `output/tables/cluster_comparison_consumption_unb.tex`, the "robustness to cluster pooling" summary table read directly into the paper; this script is the only place in the pipeline that produces it.
- Cluster-robust estimation results per row (`vv_IDN_os_covs_all`, `vv_CHN_os_covs_all`, `vv_CHN_rf_os_covs_all`, `vv_CHN_uf_os_covs_all`, `vv_TZA_os_covs_all`), each with companion never-migrant and average-return files, plus one keeplist diagnostic file per row.

It reuses `setup_grc_estimation`, `gen_vfirst`, `compute_switcher_keeplist`, `initial_values`, and `run_grc_robust_vv`, all described under `17_verdier_robust.do` above; the clustering variable differs by row (province for Indonesia, province code for both China rows, region for Tanzania), and `cluster_comparison_table` assembles the five rows into the final table.
The baseline result files this script compares against must already exist from the main GRC estimation step; the script can be interrupted and resumed, since it skips a row whose final result file already exists (`skip_if_exists`, on by default).

#### `12_counterfactuals.do`

This script reproduces the E1 misallocation accounting: the counterfactual gap between observed and potential consumption for Indonesia, Tanzania, and the two China hukou regimes, plus a population-weighted China national aggregate.
It does not run by default: it is gated behind the `$run_counterfactuals` global in `0_master.do`, off unless explicitly turned on, because it needs a Python environment (`pandas`, `numpy`) that not every replicator has configured.
Stata orchestrates the run and Python performs the computation, the same division of labor as the inversion scripts; the script first regenerates the per-cell input CSVs from the saved GRC and inversion estimates via `scripts/utilities/_export_e1_inputs.do` and `_export_e1_inputs_hukou.do`, then hands those CSVs to a Python routine, `counterfactuals.py` in `explorations/python-grc`, called through Stata's built-in `sfi` integration, that computes the aggregates, writes the results file and paper tables, and checks the new numbers against a committed baseline snapshot.

- `output/counterfactual_results.csv`: the persisted counterfactual aggregates.
- `output/tables/counterfactual_misallocation.tex`: the paper table.
- `output/tables/hukou_bound.tex`: a companion table bounding the hukou-regime results.

`README_counterfactuals.md`, alongside the scripts in `scripts/`, documents the full computation and the drift self-check against the frozen baseline snapshot in more detail.
Its prerequisites are the outputs of `5b_inversion.do` and `7_GrRC_hukou.do`, so it can only run once both have completed; it self-checks its output against the committed baseline CSV and reports a failure if the reproduced numbers drift beyond a small numerical tolerance.

#### `11b_extrapolation_support_figure.do`

This script builds the in-support figure for the paper's never-migrant extrapolation and a companion statistical test, and it runs last in `0_master.do`.
For each country it plots the density of individual rural-period mean log per-capita consumption for never-migrants and for switchers, marks the never-migrant mean, and adds a rug of per-trajectory switcher means, so a reader can see where the never-migrant mean falls relative to the range of consumption levels actually observed among switchers.
It also runs a formal support test, a robust comparison of rural-period mean consumption between never-migrants and the lowest-mean switcher trajectory, reported per country, so the paper can state whether the never-migrant mean falls within sampling uncertainty of the switcher support; singleton switcher trajectories appear in the rug plot but are excluded from the test itself, since a single observation has no estimable variance, and the count of excluded cells is reported alongside the test statistic.
The outcome is per-capita log consumption throughout, matching the scale used in GRC estimation.

- `extrapolation_support_{IDN,CHN,TZA}.pdf`/`.png`, plus `extrapolation_support_combined.pdf`/`.png`, a one-by-three panel in the paper's country order.
- `extrapolation_support_test.csv`: one row per country with the never-migrant mean, the switcher range, the identified edge trajectory, and the test statistic (gap, standard error, t-statistic, two-sided p-value).

The script initializes standalone, setting its own working-directory global if none is already set, so it can run on its own or as part of the full pipeline; because that initialization clears all previously defined programs, it must run last among any scripts that share program definitions with it, which is why it runs after the otherwise-optional `12_counterfactuals.do` in `0_master.do`.

Auxiliary programs, called from within the numbered scripts above rather than run directly:

- `0_path_config.do`. Sets the subdirectory globals (`$scripts`, `$dirdata`, `$logs`, `$output`) and the project-wide GRC constants: the GMM iteration cap, the minimum switchers per wave, and the switcher-inclusion thresholds.
- `0_setup.do`. Installs the Stata package dependencies listed under Computational requirements.
- `0_programs.do`. Defines every shared program the numbered scripts use, including `data_setup`, `run_grc`, `define_switcherpars`, `initial_values`, `grc_tex_table`, and the heterogeneity plotting programs.

Optional slice drivers, in `scripts/utilities/`, offer alternate entry points for running part of the pipeline without going through `0_master.do`.
They help when resuming an interrupted run or parallelizing the slower estimation blocks, but a standard replication does not need them.

- `utilities/run_master_resume.do`. Alternate entry point equivalent to `0_master.do`, except that it skips, rather than re-fits, any cell whose final `.ster` file is already on disk.
- `utilities/run_extras_birth.do`, `utilities/run_extras_cnu.do`, `utilities/run_extras_maxexpsh.do`. Each runs one family slice of `9_GRC_extras.do` independently: the Indonesia urban-birth cells, the Indonesia non-agricultural experience-family cells, and the max-experience-share cells across all three countries, respectively. A shared resume guard makes it safe to run these alongside `0_master.do` or each other, since it prevents duplicate estimation.
- `utilities/_export_e1_inputs.do`, `utilities/_export_e1_inputs_hukou.do`. Export the per-cell input CSVs that `12_counterfactuals.do` passes to the Python counterfactual routine, pulling trajectory shares, trajectory means, switcher returns, and the (phi, beta) point estimates off the GRC and inversion `.ster` files. `12_counterfactuals.do` calls both automatically; a standard replication does not run them on their own.

## Instructions to replicators

- Open `0_master.do` and, in the per-user directory block, set the `$dir` global to the root of this replication package.
- Run `0_master.do`. It sets the working directories, opens the master log, installs the Stata package dependencies via `0_setup.do`, loads the shared programs via `0_programs.do`, and then runs every numbered script in sequence.
- Two globals in `0_master.do` gate optional steps.
  Setting `$copyOverleaf` to 1 additionally copies the generated tables and figures to a local manuscript directory; this only matters for the authors' own writing setup, so a standard replication should leave it at 0.
  Setting `$run_counterfactuals` to 1 additionally runs `12_counterfactuals.do`, which requires Python (see Computational requirements) and requires that the inversion and hukou GRC `.ster` files already exist on disk, which the preceding steps in `0_master.do` produce.
- To resume an interrupted run without re-fitting cells whose output already exists on disk, run `utilities/run_master_resume.do` instead of `0_master.do`.
- Output lands under `output/`: `.ster` estimate files directly in `output/`, LaTeX tables in `output/tables/`, figures in `output/figures/`, switcher-inclusion audit CSVs in `output/keeplists/`, and per-script logs in `scripts/logs/` plus one timestamped master log covering the full run.
