## Approach: split Phase 1 into 1a (M11 only) and 1b (M1 + M2)

The spec's § M11 says "Doing M11 + collapse together avoids editing the same call sites twice."
That is true for keystrokes but bad for diagnostics: a Tier 2 failure in a combined commit cannot be localized to a rename bug vs a collapse bug.
M11 is a pure-rename change; M1 + M2 changes the regressor list inside `run_grc` and consolidates 6 numbered files.
Run them as two sub-phases with a Tier 2 gate in between, then a single Tier 3 at the end of Phase 1b.

The "edit same call sites twice" cost is small: the call sites that change in 1b are only the new loop in `5_GrRC.do` plus deletion of files 10--15.
Inside 0_programs.do the M11 suffix changes (`_never -> _n` etc.) and the M1/M2 option additions touch different code regions.

### 1b.2 Extend `run_grc` API

Two new options:

```stata
syntax , ..., [exp_variant(string) extra_regressor(string)]
```

- `exp_variant`: one of `none` (default), `exp`, `maxexp`, `expsh`, `maxexpsh`. Selects which of `exp`, `exp_max`, `exp_share`, `exp_max_share` enters as a regressor; `none` leaves them all out.
- `extra_regressor`: free-form varname. When non-empty, appended to the GMM regressor list. Used for the IDN birth control (and any future single-extra-regressor robustness).

Internally:

- Build the regressor list dynamically inside `run_grc` based on these options, replacing the hardcoded regressor list currently in 10--15.
- Estname construction stays caller-side, but the new estname format incorporates the variant token (e.g., the caller passes `grc_<c>_<spec3>_exp_<covs2>` for exp_variant=exp). `run_grc` does not append the variant itself; it just uses the passed estname.
- All five subgroup sters (main, _n, _a, _d, _g) are written under the caller's estname as before.

foreach exp_variant in none exp maxexp expsh maxexpsh {

## Risks

- **MAJOR**: The `extra_regressor` option might interact differently with `define_switcherpars` / `initial_values` than the bespoke 14 / 15 code did. The data-driven base selection in `initial_values` reads from the regressor list; changing the list could shift base selection and produce numerically different (though equally valid) results. Mitigated by Tier 2 TZA diff (catches drift fast).
- **MAJOR**: Phase 1a's `het_table_delta` / `het_table_mu` rename inside `0_programs.do` will break `16_heterogeneity_tables.do` if the call sites in 16 don't get updated in lockstep. Audit explicitly in Tier 1.
- **MAJOR**: M11 changes hukou ster names but `8_GrRC_hukou.do` is not exercised by the current Tier 2 (no hukou tables in `tests/reference/`). Risk that Phase 1a passes Tier 2 but breaks hukou silently. Mitigation: include the smallest hukou subgroup (e.g. CHN urban_only, fewest obs) in Tier 2 if the runtime is reasonable; otherwise accept the risk and catch in Tier 3.
- **MINOR**: The 1b.1 reference-import step assumes the live RP6 Dropbox tables for 10--15 were built from the same code as our 9-table baseline. If the coauthor re-ran 10--15 separately with different settings, our reference is wrong. Mitigation: inspect the file mtimes; if they cluster on 2026-04-22 with the 9 tables, trust them. If not, defer 1b.1 and accept that Phase 1b's Tier 3 produces a NEW reference rather than reproducing an old one.
- **MINOR**: Stata local-macro expansion inside `cond()` and nested `foreach` can silently misexpand; common failure mode is an empty token producing `grc_IDN_cuu__ca` (double underscore). Mitigation: scan logs for `__` after Tier 2.

## Critical clarification --- only `.ster` filenames change

The M11 rename touches:
- `.ster` filenames on disk (`grc_<...>.ster`).
- Stored estimate names in memory (`estimates store <name>` / `estimates use <path>`).

It does **not** touch:
- `.tex` output filenames in `RP7/output/tables/` (e.g. `GRC_CHN_consumption_urban_unb.tex`). Those stay exactly as today.
- `.pdf` / `.png` figure filenames in `RP7/output/figures/`.
- Anything Stata writes that the paper's LaTeX `\input{}`s.

This is a hard correctness requirement: the regression test diffs `RP7/output/tables/` against `tests/reference/output/tables/`, so any change to a .tex filename or content fails the test.
