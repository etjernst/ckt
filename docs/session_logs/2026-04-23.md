## Decisions made

- **VV Section F is the within-demeaning derivation.** What the previous reviewer recommended as an alternative to "saturated joint GMM" is literally what VV does on pp. 35--44. We follow VV.
- **`boottest` is the default bootstrap route**, with Kline-Santos score bootstrap as fallback and full `bsample` cluster bootstrap as validation check. Caveat: `boottest` after `gmm` doesn't re-weight the moment matrix per replication.
- **CHN sticks with `vindex(prov)`** (29 clusters). Macro-region grouping is a documented fallback, not the primary route.
- **WCB inference for all three primary specs**, not just CHN-hukou. $G \in \{19, 22, 13\}$ is too few clusters to trust analytical CR1 SEs alone.
- **Sample-matched simple-spec column** added to comparison tables so simple-vs-robust differences aren't conflated with support differences.
- **Constant-$\beta(v)$ Wald test** added to P3 alongside the LCA-overid; failing to reject would itself be a result.
- **`gen_vfirst` semantic bug confirmed:** `min(cond(!missing(v), v, .))` returns the smallest province ID, not the first-wave value. Same bug lives in `2_cluster_support_v2.do`; feasibility note may need a re-run with the corrected helper.
- **5-agent consensus method validated.** All 5 agents produced identical moment conditions and df. The "$|S|+1$ moments / $|S|-1$ df" discrepancy (which VV doesn't explicitly explain) was independently inferred by all 5 as $\alpha_0, \alpha_1$ absorbing 2 conditions.

## Approaches rejected

- **Saturated joint GMM with $|D|\times|V|$ free $\mu$'s.** Rejected per plan-review R2 and corroborated by VV Section F itself, which uses the within-demeaning estimator precisely to avoid this parameter explosion.
- **Coarser-than-province $v_i$ for CHN as the primary route.** Rejected because within-demeaning makes parameter count manageable; coarsening would weaken the identifying assumption (i.i.d. within macro-region instead of within province).
- **Hand-rolled wild-score bootstrap as the default for inference.** Demoted to fallback after confirming `boottest` v3+ supports `gmm`.
- **Manuscript prose updates inside this spec.** Out of scope; deferred to a future spec once results are in.
