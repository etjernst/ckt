\begin{frame}{Our current estimator is Verdier's ``simple'' extrapolation}

  We currently follow Suri (2011) and Tjernstr\"om (2023):
  \begin{itemize}
    \item impose the LCA restriction $\Deltai = \beta + \phicoef\, \thetai$
    \item identify $\phicoef$ from switcher trajectories
    \item extrapolate to non-migrants ($\dN$, $\dT$) along the LCA line
  \end{itemize}

  \vspace{0.8em}
  Verdier calls our approach the \emph{simple extrapolation} \& proposes a \emph{robust} alternative

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The simple extrapolation assumes i.i.d.\ non-pecuniary shocks}

  Our current Assumption A2 states that the non-pecuniary utility shock
  \[
    \nuil \quad \text{is i.i.d.\ across individuals } i, \text{ time } t, \text{ \& locations } l
  \]

  \vspace{0.6em}
  This implies:
  \begin{itemize}
    \item $\nuil$ independent of baseline skill \& comparative advantage \alert{everywhere}
    \item rules out systematic differences in $\nuil$ across regions/institutions
    \item workers in different locations have the same shock distribution, conditional on comparative advantage
  \end{itemize}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The migration literature documents what A2 rules out}

  Regional heterogeneity is a central fact of this literature:

  \vspace{0.6em}
  \begin{itemize}
    \item \textbf{Bryan \& Morten (2019):} structural model of Indonesian internal migration estimates large bilateral migration costs
    \item \textbf{Lagakos et al.\ (2020):} migration cost estimates differ substantially across developing countries
    \item \textbf{Pulido \& Swiecki (2021):} cross-sector barriers in Indonesia explain a large share of within-country income gaps
    \item \textbf{China:} hukou is an institutional source of region-specific migration barriers
  \end{itemize}

  \vspace{0.6em}
  Our current model rules this out by assumption

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Verdier's robust extrapolation weakens A2 to a conditional version}

  Decompose the non-pecuniary shock:
  \[
    \nuil \;=\; m_{l}(\vii) \;+\; \tildenu
  \]
  where $\vii$ is an observed, time-invariant individual-level index

  \vspace{0.6em}
  \textbf{New assumption (A2$'$):}
  \begin{itemize}
    \item $\tildenu$ is i.i.d.\ \emph{conditional on} $\vii$
    \item $m_{l}(\vii)$ can correlate arbitrarily with comparative advantage
  \end{itemize}

  \vspace{0.6em}
  We use first-wave province as $\vii$ to index region-level shocks (all three countries)

  \vspace{0.6em}
  \begin{alertblock}{Why this is weaker}
    A2 required \emph{unconditional} independence \\
    A2$'$ requires only \emph{within-province} independence
  \end{alertblock}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The LCA gets a province-specific intercept}

  Slope stays common; intercept varies

  \vspace{0.4em}
  Simple:
  \[
    \Deltai \;=\; \beta \;+\; \phicoef\, \thetai
  \]

  Robust:
  \[
    \Deltai \;=\; \beta(\vii) \;+\; \phicoef\, \thetai
  \]

  \vspace{0.6em}
  \begin{itemize}
    \item slope $\phicoef$ remains common---this is still the LCA restriction
    \item intercept $\beta(\vii)$ absorbs province-level $m_l(\vii)$ heterogeneity
    \item $\phicoef$ identifies off within-province switcher variation
    \item extrapolation to non-migrants happens province-by-province, then averaged
  \end{itemize}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Pooling provinces mixes differentially-selected switcher samples}

  Consider two provinces:

  \vspace{0.4em}
  \begin{itemize}
    \item \textbf{Province A} (many movers): wide switcher sample, broad range of $\thetai$
    \item \textbf{Province B} (few movers): skewed sample, only high-return types migrate
  \end{itemize}

  \vspace{0.6em}
  Pooled regression: biased by across-province difference in selection

  \vspace{0.4em}
  Within-province: clean slope, holds region-level shocks constant

\end{frame}

\section{How Suri, Verdier, and CKT identify the LCA slope}

% ---------------------------------------------------------------
\begin{frame}{Suri (2011) identifies $\phicoef$ via panel SUR \& minimum distance}

  Two-stage indirect approach on a multi-year, binary-adoption panel:

  \vspace{0.4em}
  \textbf{Stage 1 (reduced form).}
  Stack one outcome equation per year. SUR over the panel:
  \[
    y_{it} \;=\; \pi_{0,t} \;+\; \sum_{\underline{d}\in\mathcal{D}} \pi_{\underline{d},t}\, \mathbbm{1}\{\underline{d}_i = \underline{d}\} \;+\; x_{it}'\gamma_t \;+\; u_{it}
  \]
  Each coefficient $\pi_{\underline{d}, t}$ is the average $y$ in adoption pattern $\underline{d}$ in year $t$

  \vspace{0.4em}
  \textbf{Stage 2 (structural / OMD).}
  Express each $\pi_{\underline{d}, t}$ as a known function of $(\beta, \phicoef, \lambda_1, \ldots, \lambda_K)$ implied by the CRC restriction
  \[
    g_{\underline{d}, t}(\beta, \phicoef, \lambda) \;=\; \pi_{\underline{d}, t}
  \]
  Solve via weighted minimum distance: $\hat\theta = \arg\min (\hat\pi - g(\theta))' W (\hat\pi - g(\theta))$

  \vspace{0.5em}
  \begin{itemize}
    \item Identification: SUR over-identifies the structural parameters; $\phicoef$ pinned by the across-equation cross-restrictions
    \item Implemented in our \texttt{randcoef.ado}, which exactly replicates Suri's published results
  \end{itemize}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Verdier identifies $\alpha_1$ at the worker level}

  Two-step procedure on Suri's (2011) Kenyan data:

  \vspace{0.4em}
  \textbf{Step 1: Chamberlain (1992) projection.}
  Within each household, partial out a separate fixed effect for treated and untreated periods:
  \[
    y_{it} \;=\; \mu_{\text{hhid}_i,\, \D_{it}} \;+\; x_{it}'\gamma \;+\; e_{it}
  \]
  Recover worker-level $a_i$ (untreated mean) and $a_i + b_i$ (treated mean)

  \vspace{0.4em}
  \textbf{Step 2: LCA regression at worker level.}
  \[
    a_i \;=\; \alpha_0 \;+\; \alpha_1 \cdot b_i \;+\; \varepsilon_i
  \]
  $\alpha_1$ is his $\phicoef$

  \vspace{0.6em}
  \begin{alertblock}{Robust identification}
    Instrument the endogenous $b_i$ with \emph{village-demeaned} period-treatment indicators \\
    Within-village treatment variation only $\Rightarrow$ purges $m_l(\vii)$ confounders
  \end{alertblock}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{CKT identifies $\phicoef$ at the trajectory level}

  Trajectory pooling: every worker with $\underline{d}_i = \underline{d}$ has the same expected baseline
  \[
    E[\thetai \mid \underline{d}_i = \underline{d}] \;=\; \mud - \mu_{\underline{d}_0}
  \]

  \vspace{0.3em}
  Single GMM equation, one scalar $\mud$ per trajectory:
  \begin{align*}
    y_{it} \;=\; \sum_{\underline{d}} \mud \mathbbm{1}\{\underline{d}_i = \underline{d}\}
      \;+\; \Delta_{\underline{d}_0} \D_{it}
      \;+\; \phicoef \!\sum_{\underline{d}\in\DS\setminus\underline{d}_0}\!\! (\mud - \mu_{\underline{d}_0}) \D_{it} \mathbbm{1}\{\underline{d}_i = \underline{d}\}
      \;+\; \cdots
  \end{align*}

  \vspace{0.3em}
  Identification: switcher$\times$choice indicators as instruments

  \vspace{0.6em}
  \textbf{Robust variant:} same equation, switcher$\times$choice instruments \emph{village-demeaned} (just like VV)

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Asymptotically the two estimators target the same $\phicoef$}

  VV's worker-level LCA:
  \[
    a_i \;=\; \alpha_0 \;+\; \alpha_1\, b_i \;+\; \varepsilon_i
  \]

  Take expectations conditional on trajectory:
  \[
    E[a_i \mid \underline{d}_i = s]
    \;=\; \alpha_0 \;+\; \alpha_1 \,E[b_i \mid \underline{d}_i = s]
  \]

  Under trajectory pooling (A3), worker types are indistinguishable across clusters within trajectory:
  \[
    E[a_i \mid \underline{d}_i = s] = \mud, \qquad E[b_i \mid \underline{d}_i = s] = \Deltad
  \]
  so
  \[
    \mud \;=\; \alpha_0 \;+\; \alpha_1\, \Deltad
  \]
  which is exactly CKT's trajectory-level LCA $\Deltad = \beta + \phicoef\,(\mud - \mu_{\underline{d}_0})$ with $\alpha_1 = \phicoef$

  \vspace{0.5em}
  Same population $\phicoef$. Different aggregation level

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Both estimators are consistent under three assumptions}

  \begin{itemize}
    \item[\textbf{A1}] \textbf{LCA at the worker level}: $\Deltai = \beta(\vii) + \phicoef\,\thetai + \xi_i$
    \item[\textbf{A2$'$}] \textbf{Within-cluster exogeneity}: $E[u_{it}, \xi_i \mid \vii, D_{i1}, \ldots] = 0$
    \item[\textbf{A3}] \textbf{Trajectory pooling}: the distribution of $\thetai$ given $\underline{d}_i$ is the same in every cluster
  \end{itemize}

  \vspace{0.5em}
  Then $\hat\alpha_1^{\text{VV}} \xrightarrow{p} \phicoef$ and $\hat\phicoef^{\text{robust\_vv}} \xrightarrow{p} \phicoef$

  \vspace{0.6em}
  \begin{itemize}
    \item Same population parameter, different sample aggregations
    \item Asymptotic variances differ; both achieve $\sqrt{V}$-rate under cluster asymptotics
    \item When A3 fails, VV stays consistent; CKT picks up an alpha-pooling bias proportional to $\mathrm{Cov}_s(\bar\beta(s), \mud - \mu_{\underline{d}_0})$
  \end{itemize}

  \vspace{0.3em}
  Full proof: \texttt{docs/reviews/2026-04-25\_robust-vv-equivalence-proof.md}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Our first robust implementation hit a finite-sample wall}

  \texttt{run\_grc\_robust v1}: add $|V|-1$ cluster$\times$choice interactions as \emph{parameters}
  \[
    \Delta_{\underline{d}_0} \D_{it} \;\longrightarrow\; \sum_v \beta(v)\,\mathbbm{1}\{\vii = v\}\, \D_{it}
  \]
  Asymptotically equivalent to VV's instrument-demeaning approach

  \vspace{0.6em}
  \textbf{Empirical reality}: $G \in \{22, 26, 29\}$ clusters, $\sim 47$ moments
  \begin{itemize}
    \item cluster-robust weighting matrix is rank-deficient
    \item GMM objective is nearly flat in $\phicoef$ along a cluster-FE ridge
    \item TZA: two local minima---$\phicoef = -1.00$ vs $\phicoef = +1.25$ depending on initial value
    \item CHN: hung $>70$ minutes on the first fit
  \end{itemize}

  \vspace{0.4em}
  v1 retired

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Our v2 implementation moves cluster structure to the instruments}

  \texttt{run\_grc\_robust\_vv}: keep CKT's parameters, swap the instruments
  \begin{itemize}
    \item Regress $\mathbbm{1}\{\underline{d}_i = s\}\,\D_{it}$ on $\mathbbm{1}\{\vii\}$ \emph{among trajectory-$s$ workers}
    \item Use residuals as instruments for $\phicoef$ identification
  \end{itemize}

  \vspace{0.4em}
  Same parameter set as the simple GRC ($\mud$, $\Delta_{\underline{d}_0}$, $\kappa$, $\gamma$); no $\beta(v)$ parameters

  \vspace{0.6em}
  \begin{alertblock}{Why this works where v1 failed}
    No extra cluster-FE parameters $\Rightarrow$ no rank-deficient weighting matrix \\
    Cluster structure enters only through which moments contribute to identification
  \end{alertblock}

  \vspace{0.4em}
  Stable across initial values; degenerate-$v$ test matches simple onestep to 6 decimals

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{We still want to check trajectory pooling empirically}

  Trajectory pooling collapses individual workers to one $\mud$ per trajectory

  \vspace{0.4em}
  GMM moments weight clusters by
  \[
    w(s, v) \;=\; n_{s,v} \cdot \mathrm{Var}(\D \mid s, v)
  \]
  Different switchers $\Rightarrow$ different cluster weights $\Rightarrow$ if $\beta(v)$ varies, the pooled $\phicoef$ inherits a tilt

  \vspace{0.6em}
  Mean total-variation distance between switchers' weight profiles:

  \begin{center}
    \begin{tabular}{lrr}
      \toprule
      Country & mean TV & Verdier shift from simple \\
      \midrule
      IDN & $0.258$ & $37\%$ \\
      CHN & $0.038$ & $24\%$ \\
      TZA & $0.014$ & $4\%$ \\
      \bottomrule
    \end{tabular}
  \end{center}

  \vspace{0.4em}
  Suggestive: rankings match. IDN may have residual pooling bias

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The diagnostic: rebuild VV's worker-level estimator on CKT data}

  Port [firststage\_projection.do, robust.do] verbatim:
  \begin{enumerate}
    \item Chamberlain projection in CKT: absorb $(\text{pid}, \D)$ fixed effects in OLS of $y$ on covariates
    \item Extract worker-level $a_i$ and $a_i + b_i$ from the cell means
    \item 2SLS at worker level: $a_i$ on $b_i$, instrumented by village-demeaned period-treatment indicators
  \end{enumerate}

  \vspace{0.5em}
  Compare $\hat\phi^{\text{VV}}$ (worker-level) to $\hat\phi^{\text{robust\_vv}}$ (trajectory-pooled)

  \vspace{0.6em}
  \begin{itemize}
    \item \textbf{Agreement} $\Rightarrow$ trajectory pooling adds no bias; \texttt{run\_grc\_robust\_vv} stands as primary
    \item \textbf{Divergence} $\Rightarrow$ trajectory pooling matters; report Verdier with caveat \& VV as sensitivity
  \end{itemize}

  \vspace{0.4em}
  Diagnostic only---we do not propose VV's worker-level approach as the paper's main estimator

\end{frame}

\begin{frame}{What we learn---and what is still open}

  \textbf{Confirmed}
  \begin{itemize}
    \item TZA: trajectory pooling adds no detectable bias
    \item All approaches agree on the sign and broad magnitude of $\phicoef < 0$ everywhere
  \end{itemize}

  \vspace{0.5em}
  \textbf{Open}
  \begin{itemize}
    \item IDN VV-worker SE is $4\times$ Verdier's. Genuine weak ID? Or trajectory-pooling bias?
    \item Multi-switch trajectories may add noise to the worker-level Chamberlain projection
    \item First-stage $F$ for VV-worker not yet checked
  \end{itemize}

  \vspace{0.5em}
  \textbf{Provisional decision}
  \begin{itemize}
    \item \texttt{run\_grc\_robust\_vv} as primary across all three countries
    \item Add VV-worker as a sensitivity column in the main table
    \item Methods note: trajectory pooling is consistent under standard assumptions; the IDN flag is unresolved
  \end{itemize}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The move buys a weaker assumption at tractable cost}

  We gain:
  \begin{itemize}
    \item A2$'$ matches what the migration literature documents
    \item the CHN hukou split becomes a principled special case ($\vii = $ hukou) rather than an ad hoc fix
    \item stayer ATE estimates defensible against Verdier's concern in Suri's data
  \end{itemize}

  \vspace{0.4em}
  We give up:
  \begin{itemize}
    \item $\Delta_{\dN}$ averages over provinces with switcher support, not the full population
    \item thinner identification of $\phicoef$: only within-province switcher variation contributes
    \item cluster-robust standard errors at the $\vii$ level
  \end{itemize}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{An observed shifter $w_i$ provides a separate falsification test}

  Regress estimated $\thetai^{*}$ on $\Deltai$ and an observed shifter $w_i$:
  \[
    \thetai^{*} = \alpha_0 + \alpha_1 \Deltai + \alpha_2 w_i + e_i,
    \qquad H_0: \alpha_2 = 0
  \]
  Kenya: $w_i = $ distance to nearest seed seller; rejects if $\alpha_2 \neq 0$

  \vspace{0.5em}
  $w_i$ must be observed, exogenous to skill conditional on $\Deltai$, and correlated with $\nuil$

  \vspace{0.5em}
  Candidates in our data:
  \begin{itemize}
    \item distance / travel time to nearest urban center
    \item rainfall variability or pre-period climate shock (mergeable via GPS/admin code)
    \item distance to family already in urban area (closest analogue, but reflection problem)
  \end{itemize}

  \vspace{0.3em}
  None is perfect; data availability is the binding constraint

\end{frame}
