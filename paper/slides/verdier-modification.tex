\begin{frame}{Our current estimator is Verdier's ``simple'' extrapolation}

  We currently follow Suri (2011) and Tjernstr\"om (2023):
  \begin{itemize}
    \item impose the LCA restriction $\Deltai = \beta + \phicoef\, \thetai$
    \item identify $\phicoef$ from switcher trajectories
    \item extrapolate to non-migrants ($\dN$, $\dT$) along the LCA line
  \end{itemize}

  \vspace{0.8em}
  Verdier calls our approach the \emph{simple extrapolation} \& proposes a \emph{robust} alternative.

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The simple extrapolation assumes i.i.d.\ migration-cost shocks}

  Our current Assumption A2 states that the non-pecuniary utility shock
  \[
    \nuil \quad \text{is i.i.d.\ across individuals } i, \text{ time } t, \text{ and locations } l.
  \]

  \vspace{0.4em}
  The migration-cost shifter is independent of baseline skill and comparative advantage \alert{everywhere in the sample}.

  \vspace{0.4em}
  This rules out any systematic difference in migration-cost distributions across regions, institutions, or subpopulations.

  \vspace{0.6em}
  \begin{alertblock}{Practical reading}
    Two workers in different parts of the country face the same cost distribution, conditional only on their own comparative advantage.
  \end{alertblock}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The migration literature documents exactly what A2 rules out}

  Regional variation in migration cost is the central fact of this literature:

  \vspace{0.6em}
  \begin{itemize}
    \item \textbf{Bryan \& Morten (2019):} Indonesian migration costs near the world misallocation frontier.
    \item \textbf{Lagakos et al.\ (2020):} migration costs vary substantially within and across developing countries.
    \item \textbf{Pulido \& Swiecki (2021):} sector frictions correlate with regional productivity.
    \item \textbf{China specifically:} hukou generates large, regionally-varying barriers.
  \end{itemize}

  \vspace{0.6em}
  \begin{alertblock}{}
    Our current model rules this out by assumption.
  \end{alertblock}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Verdier's robust extrapolation weakens A2 to a conditional version}

  Decompose the migration-cost shock:
  \[
    \nuil \;=\; m_{l}(\vii) \;+\; \tildenu,
  \]
  where $\vii$ is an observed, time-invariant individual-level index.

  \vspace{0.6em}
  Only the residual $\tildenu$ is i.i.d.\ \emph{conditional on} $\vii$. The region-level component $m_{l}(\vii)$ can correlate arbitrarily with comparative advantage.

  \vspace{0.6em}
  We use first-wave province (all three countries).

  \vspace{0.6em}
  \begin{alertblock}{Why this is weaker}
    A2 required \emph{unconditional} independence. A2$'$ requires only \emph{within-province} independence.
  \end{alertblock}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The LCA gets a province-specific intercept}

  Slope stays common; intercept varies.

  \vspace{0.4em}
  Simple:
  \[
    \Deltai \;=\; \beta \;+\; \phicoef\, \thetai.
  \]

  Robust:
  \[
    \Deltai \;=\; \beta(\vii) \;+\; \phicoef\, \thetai.
  \]

  \vspace{0.6em}
  \begin{itemize}
    \item Slope $\phicoef$ remains common---this is still the LCA restriction.
    \item Intercept $\beta(\vii)$ absorbs province-level cost heterogeneity.
    \item $\phicoef$ identifies off within-province switcher variation.
    \item Extrapolation to non-migrants happens province-by-province, then averaged.
  \end{itemize}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{Pooling provinces mixes differentially-selected switcher samples}

  Consider two provinces:

  \vspace{0.4em}
  \begin{itemize}
    \item \textbf{Low-cost province} (coastal). Many types migrate; switcher sample covers a wide range of $\thetai$.
    \item \textbf{High-cost province} (remote). Only high-return types migrate; switcher sample is skewed.
  \end{itemize}

  \vspace{0.6em}
  Pooled regression: biased by across-province difference in selection.

  \vspace{0.4em}
  Within-province: clean slope, holds migration cost constant.

  \vspace{0.6em}
  \begin{alertblock}{}
    Partialling out $\vii$ purges this selection bias.
  \end{alertblock}

\end{frame}

\begin{frame}{Implementation adds $\vii$-interacted means to the GRC regression}

  Currently:
  \begin{align*}
    y_{it} = \sum_{\underline{d}} \mud \mathbbm{1}\{\underline{d}_i = \underline{d}\}
            + \Delta_{\underline{d}_0} \D_{it}
            + \sum_{\underline{d}\in\DS\setminus\underline{d}_0} \phicoef(\mud - \mu_{\underline{d}_0}) \D_{it}\mathbbm{1}\{\underline{d}_i=\underline{d}\}
            + \cdots + \varepsilon_{it}.
  \end{align*}

  \vspace{0.3em}
  Under robust: trajectory means $\to$ trajectory $\times$ province means.
  \begin{align*}
    y_{it} = \sum_{\underline{d},v} \mu_{\underline{d},v}\, \mathbbm{1}\{\underline{d}_i=\underline{d}, \vii=v\}
            + \Delta_{\underline{d}_0}\D_{it}
            + \phicoef \sum_{\underline{d}\neq\underline{d}_0} (\mu_{\underline{d},\vii} - \mu_{\underline{d}_0,\vii})\D_{it}\mathbbm{1}\{\cdot\}
            + \cdots
  \end{align*}

  \vspace{0.4em}
  \begin{itemize}
    \item Slope $\phicoef$ unchanged---still a single scalar.
    \item Standard errors cluster at $\vii$.
    \item Stayer return $\Delta_{\dN}$ averaged over clusters with switcher support.
  \end{itemize}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The cost-shifter diagnostic is a falsification test, not a substitute}

  Verdier proposes a diagnostic via observed continuous cost shifter $w_i$:

  \vspace{0.3em}
  \[
    \thetai^{*} = \alpha_0 + \alpha_1 \Deltai + \alpha_2 w_i + e_i,
    \qquad H_0: \alpha_2 = 0.
  \]

  In Kenya he uses $w_i = $ average distance to nearest seed seller.

  \vspace{0.6em}
  \begin{itemize}
    \item Requires an observed exogenous cost shifter.
    \item Falsifies the simple extrapolation if $\alpha_2 \neq 0$.
    \item Does not deliver an alternative estimate.
    \item Not required for the robust extrapolation, which uses $\vii$.
  \end{itemize}

  \vspace{0.6em}
  \begin{alertblock}{}
    We focus on $\vii = $ province; cost-shifter test is future robustness.
  \end{alertblock}

\end{frame}

% ---------------------------------------------------------------
\begin{frame}{The move buys a weaker assumption at tractable cost}

  We gain:
  \begin{itemize}
    \item A2$'$ matches what the migration literature documents.
    \item The CHN hukou split becomes a principled special case ($\vii = $ hukou) rather than an ad hoc fix.
    \item Stayer ATE estimates defensible against Verdier's concern in Suri's data.
  \end{itemize}

  \vspace{0.4em}
  We give up:
  \begin{itemize}
    \item $\Delta_{\dN}$ averages over provinces with switcher support, not the full population.
    \item Thinner identification of $\phicoef$: only within-province switcher variation contributes.
    \item Cluster-robust standard errors at the $\vii$ level.
  \end{itemize}

\end{frame}

  \end{itemize}

\end{frame}
